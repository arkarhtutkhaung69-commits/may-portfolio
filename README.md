# May Thet Thet Khaing – Portfolio

Files: index.html (structure), css/style.css (design), js/main.js (behaviour),
make_data.py (optional, makes data/sales.json), images/may.jpg (your photo).

Run in VS Code:
1. File > Open Folder > choose this folder.
2. Install the "Live Server" extension.
3. Right-click index.html > Open with Live Server (opens http://127.0.0.1:5500).

Optional: `python make_data.py` to regenerate the chart data.
